# 유선희

**Android 앱 개발 · 데이터 수집 및 분석**

## 소개

Java로 Android 앱의 의약품 등록과 복용 알림 기능을 개발했습니다. Azure 기반 팀 프로젝트에서는 공공입찰 데이터를 수집·검증하고, 거래 데이터와 수출 수익성을 분석했습니다.

- **OOO대학교** (2020.03–2026.08) | IT공학전공(주전공), 통계학(복수전공) 졸업
- **Microsoft Data School 4기** (2026.03–2026.09) | Azure 기반 데이터·AI 프로젝트 수행

## 기술 스택

- **언어** Python, C, Java, JavaScript, SQL
- **모바일** Android
- **데이터** PySpark, Databricks, Microsoft Fabric, Azure SQL Database
- **웹·데이터 앱** FastAPI, Streamlit
- **AI** Azure OpenAI, Azure AI Search, RAG
- **인프라** Azure
